# Toolkit pilot evidence

Baseline and post-install `npm run check` built the PWA and single-file bundle and passed 41 unit and 27 browser checks each. The browser PWA capture passed four fresh contexts before and after installing the web profile. Dry-run listed 25 additions; the second apply reported 25 identical entries.

The branch includes the web tools, three skills, a PWA browser scenario and a dev-only Playwright lockfile pin. See [art and polish audit](ART_AND_POLISH_AUDIT.md) for commands, viewport evidence and production priorities. Native mobile acceptance remains open.
