# Implementation Priorities and Structured Backlog

P0 — Keep the game functional: smoke tests, 28-level continuity, save compatibility, DEV skip, accessibility and responsive layout.

P1 — Core art direction and system: scene components, character roster, UI typography/palette, material language for physical objects, animated layered backgrounds, evidence displays.

P1 — Complete puzzle presentation polish: all seven types contextualised; visuals clearly show game mechanics and target state. Keep puzzles solvable and fluid on touch.

P1 — Sound: ambient rain/room tone, original suspense music, contextual audio and settings; user gesture audio unlock.

P1 — Narrative feel: opening cinematic, seamless scene/puzzle/reveal transitions, story text pacing and chapter title cards without progress-killing delays.

P2 — Advanced debug overlay: stage selector, scene fast-forward, jump-to-chapter, sound audition, show current state. Sandbox/save-copy rather than overwriting canonical save, if possible.

P2 — Optional enhancement: installable PWA and later Capacitor Android APK. Never delay the quality of the offline HTML build for packaging work.

**Finish line:** a playable game, not just an architecture rewrite. All gameplay, sound and polished visuals must be present in the final delivered files. Update tests and screenshots with evidence.
